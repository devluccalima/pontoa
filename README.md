
# Pontoa

Sistema de ponto de venda (PDV) modular, responsivo e multinegócio, desenvolvido para pequenos comerciantes, feirantes e operações de alimentação.

## Objetivo

Digitalizar pedidos, comandas, pagamentos e controle de caixa, simplificando a operação diária de pequenos estabelecimentos.

## Funcionalidades previstas para o MVP

- Cadastro de produtos e categorias
- Criação e acompanhamento de pedidos
- Comandas por nome ou número
- Controle de status de preparo e entrega
- Pagamentos independentes do status de entrega
- Abertura e fechamento de caixa
- Dashboard de vendas
- Usuários com permissões
- Estrutura multinegócio
- Interface responsiva

## Tecnologias

- React + TypeScript + Tailwind CSS
- Python + FastAPI
- PostgreSQL
- SQLAlchemy + Alembic
- Docker Compose

## Estrutura

- `frontend/`: interface do sistema
- `backend/`: API e regras de negócio
- `infra/`: infraestrutura e containers
- `docs/`: documentação técnica
- `scripts/`: utilitários de desenvolvimento
